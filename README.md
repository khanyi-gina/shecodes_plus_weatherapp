# WeatherApp
Created with CodeSandbox

This is Vanilla JavaScript weather app. My second project from SheCodes Plus, an advanced 8-week JavaScript coding workshop. This project has API’s, real-life development workflow. It collects real life data - day, time and weather condition after searching any city in the world.
